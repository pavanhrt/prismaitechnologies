AI Consulting

Strategy before software.

Most AI projects fail because the wrong problem got picked. We start with your actual workflows, cost out the options, and tell you which one is worth doing — including when the honest answer is 'not this'.

Start a project How we work

Overview

There is enormous pressure to do something with AI. That pressure produces pilots that demo well and die quietly, because nobody checked whether the underlying process was worth automating in the first place.

Our consulting engagement is deliberately unglamorous. We sit with the people doing the work, map what actually happens (not what the process document claims), and measure where time and money leak. Then we cost each option — build, buy, integrate, or leave alone — against the value it would release.

You get a recommendation you can act on, with the reasoning shown. If the numbers do not support building anything, we will say so. That answer is worth more than a pilot that quietly stalls after six months.

The problem

What usually brings people here.

If more than one of these sounds familiar, this is the right page.

Where it hurts
  • Leadership wants an AI strategy, but nobody can point to which process it should touch first.
  • A pilot was built, demoed well, and never made it into daily use.
  • Vendors are quoting wildly different numbers for what sounds like the same thing.
  • Nobody can say what the current process actually costs, so there is no baseline to improve against.
What we do about it
  • A workflow audit that documents what really happens, timed and costed per step.
  • Options priced side by side: build, buy, integrate, or leave alone.
  • A single ranked recommendation with the reasoning visible, not a menu.
  • A baseline you can measure against after the fact, so success is checkable.

Process

How the engagement runs.

Each stage produces something you can hold, review and act on — so you always know where the work stands.

Discovery

We interview the people who run the process daily, not just the people who own it on the org chart. Most of the useful detail lives with whoever handles the exceptions.

Output: Process map with real step timings

Baseline

We attach cost and time to each step: staff hours, rework, delay, error rate. This is the number every later claim gets measured against.

Output: Costed current-state baseline

Option costing

For each candidate intervention we estimate build cost, run cost, and realistic time-to-value. Off-the-shelf tools are compared honestly against building.

Output: Comparison of 3–5 costed options

Recommendation

One recommended path, the reasoning behind it, and the conditions under which we would advise against proceeding.

Output: Written recommendation and roadmap

Where it applies

Representative engagements.

Illustrative scenarios drawn from the kinds of work this service covers, written to show the shape of the problem rather than to name clients.

Multi-speciality hospital

Discharge summary backlog

Doctors were spending evenings writing discharge summaries from handwritten notes. We timed the process, tested drafting assistance on de-identified samples, and modelled the review burden.

Recommendation: draft-and-review, not full automation
Manufacturing unit

Quality report consolidation

Shift supervisors were re-keying inspection data into three systems. The audit found the duplication cost more than any model would save.

Recommendation: integrate first, automate later
Engineering college

Admission enquiry handling

Enquiries arrived by phone, WhatsApp and walk-in with no shared record. We mapped the funnel before proposing anything.

Retail chain

Stock reorder decisions

Reordering ran on one manager's memory. We baselined stockout cost, then compared forecasting options against a simple rules engine.
